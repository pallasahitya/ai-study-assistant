# AI Study Assistant

AI Study Assistant is a full-stack web application that enables users to upload PDF documents, interact with them using AI-powered conversations, and receive context-aware answers generated by Gemini 2.5 Flash.

---

## Features

- AI-powered PDF Chat
- PDF Upload & Processing
- Context-Aware Question Answering
- PDF Summarization
- Markdown Response Rendering
- Syntax Highlighting for Code Blocks
- Auto Scroll Chat Interface
- Enter-to-Send Messaging
- Loading Animations
- New Chat Support
- Automatic PDF Reset/Clearing

## Installation

### Clone Repository

```bash
git clone https://github.com/pallasahitya/ai-study-assistant.git
cd ai-study-assistant
```

---

## Frontend Setup

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

## Backend Setup

Move to backend folder:

```bash
cd backend
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start FastAPI server:

```bash
uvicorn main:app --reload
```

---

## Environment Variables

Create a `.env` file inside the `backend` folder:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

---

## Application Workflow

1. Upload a PDF document.
2. PDF content is extracted using PyMuPDF.
3. User asks questions related to the document.
4. Gemini 2.5 Flash processes the document context.
5. AI generates relevant answers and summaries.
6. Responses are displayed in an interactive chat interface.
